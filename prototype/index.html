已按你的答案实现

  • 桌面小组件：4×2 今日课表 + 两个 2×2 小尺寸，自动淡化已上过的课
  • 学期设置：第一周起始日 + 总周数 + 当前周，课表顶部显示真实日期区间
  • 重叠课程并排：左右分栏 + 竖排课名 + 「2 门」角标，不再互相遮盖
  • 视觉：两套完整主题（柔光 / 墨影），右上角切换；课程块圆角 + 色条 + 悬停浮起

请你定这 5 件事

  • 主题：柔光 / 墨影只留一套，还是两套都做（跟随系统自动切）？
  • 课程块信息：现在只显示课名 + 教室。要不要再挤进教师名？（会更挤）
  • 重叠课程：竖排分栏能接受吗？也可以改成「层叠 + 2 门角标，点击展开」
  • 小组件：要哪几种尺寸？4×2 / 2×2 / 4×1 简洁条，可多选
  • 配色：主色现在是蓝紫。要不要换成别的，或者做成可自选强调色？

原型没画、但你可能想要的

  • 课程编辑表单（课程名 / 教师 / 教室 / 周次范围 / 单双周 / 颜色）
  • 首页下拉显示「明天有 3 门课」的提醒卡
  • 课表截图分享（带水印的图片，发给同学）
  • 课前提醒 —— 你这次没勾，我先不做，需要随时说

说明

  • 这是网页原型，用来先确认视觉和交互；确认后我再改 Android 代码，避免反复打包
  • 日期按真实历法排：2026-09-01 是周二，所以第 3 周 = 9/14–9/20，今天 9/15 周二
  • 课程数据是编的示例，便于你看密度；左侧时间列每节同时显示上课与下课时间
  • 点击任意课程块可弹出详情卡，验证交互手感
